# Как внести вклад

Спасибо за интерес к Video Montage! Проект открыт под лицензией GPL-3.0, и любые
улучшения приветствуются — от багфиксов до новых фич.

## С чего начать

```bash
git clone https://github.com/gitmir-hello/video-montage.git
cd video-montage
npm install          # заодно скачает бинарник ffmpeg
npm run dev          # бэкенд :3001 + фронтенд :5173
```

Открой http://localhost:5173. ffmpeg ставить вручную не нужно — он подтягивается
пакетом `ffmpeg-static`.

## Проверка перед PR

```bash
npx tsc --noEmit     # типы должны быть чистыми
npm run build        # прод-сборка должна проходить
```

Если менял бэкенд — прогони ручной сценарий: создай проект, загрузи видео и mp3,
собери mp4, проверь результат через `ffprobe`.

## Структура проекта

```
server/
  index.js       # Express: роуты проектов, загрузка медиа, экспорт, раздача /media
  projects.js    # файловое хранилище проектов (data/projects/<id>/)
  ffmpeg.js      # обёртки над ffmpeg/ffprobe: кадры, кроп, вырезы, микс, сборка
src/
  App.tsx        # корневой компонент, состояние проекта, оркестрация
  useTransport.ts# синхронное превью (видео = мастер-часы, аудио по окнам)
  api.ts, types.ts
  components/     # ProjectPicker, Timeline, TransportBar, CropOverlay, ImportDialog, …
  styles.css     # весь HUD-дизайн (без фреймворков)
```

## Стиль

- **TypeScript** на фронте, чистый **ESM JavaScript** на бэке.
- Комментарии — по-русски, короткие, объясняют «зачем», а не «что».
- Никаких новых зависимостей без веской причины — проект намеренно лёгкий.
- HUD-эстетика: острая геометрия (без скруглений), cyan-акцент, шрифты Onest +
  JetBrains Mono. Держись существующих CSS-токенов в `styles.css`.

## Pull requests

1. Форкни репозиторий и создай ветку от `main`.
2. Делай атомарные коммиты с понятными сообщениями.
3. Опиши в PR, что и зачем меняется; приложи скриншот для UI-изменений.
4. Убедись, что `tsc` и `build` проходят.

## Баг-репорты

Открой [issue](https://github.com/gitmir-hello/video-montage/issues) с шагами
воспроизведения, ОС, версией Node и, если возможно, характеристиками видео
(разрешение, кодек, длительность).
